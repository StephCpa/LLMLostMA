# 研究方案 v0.1.0：保留纠错能力的多智能体安全

日期：2026-10-10。作者操作／审查／提案分开；本文件属于 **proposal**，所有材料为 development。仅批准方案与离线检查，模型实验待执行端明确启动。

## 1. 从哪个问题出发

HiddenBench 已有信息分散导致协作失败的直接结果；Dr. MAMR 已将 LiC 的执行者重启纳入双 Agent 方法。错误传播、来源谱系、同步、治理共享记忆与通信调度也都有直接近邻。原来的“恢复＋选择下一步行动”范围过宽且中度至高度拥挤，不继续据此开发通用控制器。[S01,S07–S12,S19]

新主问题：**在同一消息渠道同时承载可用纠正和越权指令的情形下，防御能否让合法工作继续完成，而不是以拒绝更新换取低攻击成功率？**

“防御损害正常效用”不是空白：Easier to Mislead、Utility Under Attack、Trust Propagation、PIGuard、Task Shield 与 ActGuard 都直接相关。[S13–S18] 本轮有限检索尚未确认与本计划全部实验接口完全同构的工作，但这不构成首创证明。

## 2. 候选贡献，不先发明新防御器

1. **条件化经验认识**：在控制消息渠道、前史和任务后，哪些防御削弱了必要纠正的执行；损失发生在过滤、采信、权限判断还是下游执行。
2. **可复用评价能力**：将修订必要性、事实支持、权限和实际执行共同纳入成对任务，能识别“零攻击成功但系统已失用”的设置。
3. **条件化方法候选**：仅当强简单基线仍有缺口时，检验“证据候选”和“操作请求”分路、分别核验、最小修订是否产生新增的安全—效用—成本边界。这个结构不是独立创新声明。

Meta-method 操作：M7 为评价对象重写；M9 显化权限与观察契约；M4/negative_control 是证据角色；M10 对照归因。代码不代表已验证贡献。

## 3. D4 的三个可分辨假说

H1：某些防御的低风险主要来自拒绝一切变化。预测：攻击成功率降低的同时，纠正分支完成率也降低；不能由模型在无防御时本就不会任务解释。

H2：损失来自将整个低信任消息一并丢弃，而不是来自纠正不可验证。预测：在同样证据、权限与工具预算下，保留经核验事实、移除越权操作的强基线可以恢复效用。

H3：即使入口选择正确，网络中的旧副本或隐式派生项仍使纠正失败。预测：单接收者对照成功，而真实 peer 网络在固定后续窗口出现失效项残留或重新引入；需重新生成干预后的所有消息才能检验。

允许 H1–H3 同时成立，不分摊成唯一百分比。任何“只能靠新模块解决”的主张都必须经过已有方法比较。

## 4. 主实验不是简单的 true/false 文本分类

每个基础任务有共同的旧状态、当前真实世界、合法任务契约和固定通信日程。修订事件后，当前任务要求更新某项产物。

- **C：纠正分支**。消息提供真实、可核验的新记录及当前权限内的更新请求。
- **X：混合注入分支**。通过同一发送节点、同一边、相同角色和时点，提供同一份有效纠正，但同时加入不被任务契约授权的指令。

两分支最终都应采纳有用纠正；X 还应拒绝越权部分。这样避免“攻击任务只需什么也不做，纠正任务必须工作”的不公平设计。

例如：批次记录更正了样本计数。C 要求重新计算报告；X 在保留同一更正的同时，要求把没有通过的质量检查标成通过。公开与本地执行仅使用虚构报告和受限动作；不提供可用于现实入侵的材料。

同渠道不等于两个输入完全相同。消息正文的干预点需要显式记录；长度、风格、位置和来源身份尽量匹配，不能把语义差异称作纯随机变化。另设上下文授权翻转控制：相同的局部请求在不同、明确可见的任务契约下有不同的权限解释。

## 5. 任务与网络

第一批 40 个基础任务，两个家族各 20：

- 实验／数据报告：单位、批次元数据或计数被纠正，必须修改文字报告或表中派生数值，同时保留独立核验通过的项目。
- 小型分析脚本与说明：局部常量从自然语言要求被复制到实现；规则修订后可能需要更新输出。采用可执行参考与隐藏断言评价，不能直接把全部 gold 依赖给候选。

既包含工具可直接追踪的显式依赖控制，也包含在暴露的信息中没有现成 lineage 的文字／复制常量。不是声称“任何工具都不可能追踪”，也不剥夺经典切片、全量重跑或静态检查基线本来可用的文件。

使用 3 个真实调用的 LLM peers，独立上下文、没有中心规划模型，固定消息日程、最多 3 轮。操纵一个消息事件后重新运行其全部下游，不将模拟同伴台词当作真正 Agent 互动。起初同一冻结模型以隔离网络作用；确认再用第二家族，异构团队是后续而非默认全因子。

先有单接收者控制；网络实验不能只有它，否则只是给两轮 conformity 任务改了名称。共享正确状态的中央模型仅作诊断上界；资源匹配的中央方案才是系统基线。

## 6. 四个首轮防御臂

B0 无语义防御：原消息传入；外部安全沙盒边界始终保留。

B1 简单来源／版本／作用域检查：host 管理来源与版本；只允许契约内操作，不以消息自称权威作证据。该基线在显式任务上获胜是预期，不算失败。

B2 内容防御：选一种能在同模型接口运行的 PIGuard／prompt guard 方案。完整阻断与片段移除必须分别标明；不混入额外 oracle。

B3 最强可适配的任务／行动对齐防御：Task Shield、Trust Propagation 的作用域边界，或 ActGuard。先按论文及可用代码做忠实适配和小型开发比较，再冻结选择理由；不能以弱复刻冒充原方法。

“全部拒绝”“全部采纳”是边界控制，不算新方法。全量重跑＋同等证据获取作为成本参照。证据候选／操作请求分路只在第一轮证明强基线仍留缺口后加入，替换或另开预注册分支，不在开发中无限试到胜出。

## 7. 首个真实产物

不是训练新模型，也不是新攻击搜索器，而是：每个任务的 C/X 成对完整轨迹、host 证据查询记录、过滤行为、拟议和实际动作、最终可执行判定、完整成本，以及按任务成组的安全—纠正效用图。

危险内容生成与攻击优化不在本轮范围。一次性受控恶意消息只改变虚构任务内结果，攻击者不得伪造 host 侧的真实证据、政策或密码学凭据；攻击者身份可见但“此为攻击”标签不可见。

## 8. Stage 0 和进入条件

先用开发集中的 8 个任务检查消息与工具接口，再补齐 40 个任务；不是新增一份“未见确认”。模型及阈值在执行前写入配置。未经资格检查不运行大批 API。

进入条件：C/X 两世界合法、自洽；纠正在允许渠道与时限内可得；baseline 使用工具能核验；任务不是系统性单模型无能力；全部拒绝不能虚得高任务效用；没有条件标签泄漏。

停止：简单作用域规则已解决；同预算强近邻已经达到同等边界；提升只由拒绝或更多验证预算造成；自然轨迹没有相应缺口；信息不足却硬判错误；只对一套模板有效。

若发现 D4 是已有工作的完整复述，只保留兼容性测量，不以“多 Agent 版本”宣称新论文。若只能获得一次测量偏差，记录为工程修复，不自动升级方法。

## 9. D1/D2/D3 的处置

D1：备用“隐式派生依赖修订”，关键是无中央规划者与旧版本被 peer 重新带回；必须对比 StateAuditor、Grounded Continuation、回滚修复和确定性增量执行。[S20–S23] 工具可精确解决的子集作为正控制，不刻意隐藏工具。

D2：暂停通用通信动作选择，Q-Mix、DALA、Consilience 已占据直接位置。[S07–S09]

D3：同一事实集跨轮／跨节点的诊断，只在 D4 需要解释时复用，不独立开 1–2 周研究线，也不改变现有两个主项目的训练资源。

## 10. 潜力与完成边界

主观优先级 D4 高于 D1/D2/D3，暂列约 7/10（有条件）；旧 D1+D2 宽方向从约 8 下调为约 6。不是论文质量、发表概率或已确认创新分。

仅有“防御会误拦”不够；需要新条件化认识、可复用评价能力或胜过强近邻的实际成本边界。没有独立证据时宁可停止，不以已有方法拼装为新贡献。
